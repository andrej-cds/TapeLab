CDS TapeLab - XP izdaja 0.6.0
======================================

Za Windows XP SP3 (32-bit) in novejše. Brez namestitve: mapo prekopiraj na računalnik in zaženi CDSTapeLab.exe.

POTREBNO NA RAČUNALNIKU
1. Windows XP SP3.
2. Microsoft .NET Framework 4.0 (ali 4.0 Client + Full) - "dotnetfx40_full_x86_x64.exe". Za XP je to zadnja podprta različica.
3. Zvočna kartica z ASIO gonilnikom. SB Live: kX Project gonilniki z vklopljenim ASIO (kX ASIO). Alternativa: ASIO4ALL.
   SB Live dela samo pri 48 kHz, zato je frekvenčni odziv omejen na približno 20 kHz.

PRVI ZAGON
- Odpri Settings (Nastavitve) in izberi ASIO gonilnik (kX ASIO). Vzorčenje pusti na samodejno.
- Licenca v tej izdaji ni potrebna: program deluje v celoti.
- Snemanje videa (MP4) pri azimutu v tej izdaji ni na voljo.

ČE KAJ NE DELA
Pošlji datoteko  %AppData%\CDSTapeLab\log.txt   (v Raziskovalcu vpiši to v naslovno vrstico).
V njej so podatki o računalniku, ASIO gonilnikih in napakah.
