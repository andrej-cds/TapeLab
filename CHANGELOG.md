# Changelog

## 0.6.0 (2026-11-10)
- Head azimuth: **Lissajous view** next to the phase trace (L on X, R on Y; in phase = 45° line; green ellipse = chosen tolerance ±2 / ±5 / ±10 µs).
- Start screen shows the real ASIO driver and sample rate. Settings: **Input test** button (level on all input channels of the driver).
- Windows XP edition follows the main program and is no longer marked as test/beta.
- The project is now **free software (AGPL-3.0)** with public source and automatic builds on GitHub.

## 0.5.0
- New tile **True RMS Voltmeter (mV)**: left (blue) and right (red) channel on a full-width scale; measured ranges 9, 90, 200, 500 mV with the nominal value at the centre plus 1 mV – 10 V; range per channel or locked; calibration against a reference instrument.
- Windows XP edition (.NET Framework 4.0, x86).

## 0.4.0
- **Head azimuth** (phase difference of the channels from a 10 / 12.5 / 15 kHz tone, tolerance zone ±2 / ±5 / ±10 µs).
- Playback frequency response: animated bars, maximum per channel, start maximised.
- Gold CDS icon; export file names `Prefix_dd.mm.yy;NN`.
